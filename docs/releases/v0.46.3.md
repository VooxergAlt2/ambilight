# Ambilight ESP32-C6 v0.46.3

First public binary release of the current ESP32-C6 Ambilight firmware line.

## Highlights

- HyperHDR realtime RGB over DDP UDP/4048.
- Four synchronized PARLIO LED outputs with runtime COUNT/GPIO/FWD/REV mapping.
- Optional VL53L5CX wall-distance correction with DISABLED / SHADOW / ACTIVE modes.
- WLED-compatible Home Assistant facade for power, brightness, RGB and local effects.
- Web UI for commissioning, diagnostics, Wi-Fi provisioning and ToF setup.
- Versioned JSON configuration backup/restore.
- NVS-preserving normal firmware updates and non-destructive handling of unknown settings schemas.
- Physical disabled-pixel mask that remains effective for DDP, manual effects and commissioning output.

Windows/HyperHDR setup is documented in [`docs/windows-hyperhdr.md`](../../blob/v0.46.3/docs/windows-hyperhdr.md).

## Which binary should I use?

| File | Purpose | Flash offset | Settings |
| --- | --- | ---: | --- |
| `firmware.factory.bin` | **First installation / blank board.** Combined image containing bootloader, partition table, boot app and firmware. | `0x0` | May overwrite NVS. Do not use for a normal update when settings must be preserved. |
| `firmware.bin` | **Normal update of an already configured v0.46.x controller.** Application image only. | `0x10000` | Preserves the dedicated NVS partition. |
| `bootloader.bin` | Advanced recovery/component flashing only. | `0x0` | Not needed for a normal update. |
| `partitions.bin` | Advanced recovery/component flashing only. Current 16 MiB partition table. | `0x8000` | Changing the partition table is an advanced operation. |
| `boot_app0.bin` | Advanced recovery/component flashing only. OTA boot selector helper used by the combined factory image. | `0xE000` | Not needed for a normal update. |
| `SHA256SUMS.txt` | SHA-256 hashes for all release binaries. | - | Use to verify downloads. |

## Windows quick install

Install Python and esptool:

```powershell
py -m pip install --upgrade esptool
```

For a blank controller, replace `COM5` with the board's port:

```powershell
py -m esptool --chip esp32c6 --port COM5 write-flash 0x0 firmware.factory.bin
```

For a normal update while keeping settings:

```powershell
py -m esptool --chip esp32c6 --port COM5 write-flash 0x10000 firmware.bin
```

Do **not** run `erase-flash` before a normal update. Back up the configuration from **System -> Configuration backup** before maintenance work.

If esptool cannot connect, put the board into its download/bootloader mode according to the board vendor's instructions, commonly by holding **BOOT** while resetting or reconnecting USB.

## HyperHDR

No custom Windows plugin is required. Configure the controller as a standard **DDP** device:

- protocol: DDP
- port: UDP/4048
- address: controller IP
- LED count: sum of the four active sides shown by the controller Web UI

Do not select WLED realtime UDP or HyperHDR Hyperk for this firmware.

## Validation

Release candidate validation:

- partition check: PASS
- embedded Web UI structural check: PASS
- native tests: **270 / 270 PASS**
- ESP32-C6 build: PASS
- RAM: **95,460 / 327,680 bytes (29.1%)**
- application image: **1,348,180 / 7,340,032 bytes (18.4%)**

## Known limitations

- OTA upload over Wi-Fi is not implemented yet. The flash layout already reserves dual application slots for future OTA work.
- The Web UI has no separate authentication. Keep HTTP/80 on a trusted LAN.
- Wi-Fi passwords are intentionally excluded from JSON configuration backups.

# Ambilight ESP32-C6 v0.46.3 — описание на русском

Первый публичный бинарный релиз текущей ветки прошивки для ESP32-C6.

## Что входит

- realtime Ambilight из HyperHDR по DDP UDP/4048;
- четыре синхронных PARLIO-выхода;
- настройка COUNT/GPIO/FWD/REV без перекомпиляции;
- опциональная ToF-коррекция по VL53L5CX;
- Web UI для настройки, пусконаладки и диагностики;
- WLED-compatible интерфейс для Home Assistant;
- JSON backup/restore конфигурации;
- сохранение NVS при обычном обновлении `firmware.bin`;
- резервная Wi-Fi AP при отсутствии подключения к основной сети.

## Какой BIN использовать

| Файл | Назначение | Offset | Настройки |
| --- | --- | ---: | --- |
| `firmware.factory.bin` | Первая установка на пустую плату. Полный combined image. | `0x0` | Может перезаписать NVS. Не использовать как обычное обновление. |
| `firmware.bin` | Обычное обновление уже настроенного контроллера. | `0x10000` | Сохраняет отдельный NVS-раздел. |
| `bootloader.bin` | Ручное восстановление / advanced flashing. | `0x0` | Обычному пользователю не нужен. |
| `partitions.bin` | Таблица разделов 16 MiB. | `0x8000` | Менять вручную только осознанно. |
| `boot_app0.bin` | Служебный OTA boot helper. | `0xE000` | Обычному пользователю не нужен. |
| `SHA256SUMS.txt` | SHA-256 всех бинарников. | - | Для проверки скачанных файлов. |

## Быстрая установка в Windows

Установить esptool:

```powershell
py -m pip install --upgrade esptool
```

Первая установка:

```powershell
py -m esptool --chip esp32c6 --port COM5 write-flash 0x0 firmware.factory.bin
```

Обновление без сброса настроек:

```powershell
py -m esptool --chip esp32c6 --port COM5 write-flash 0x10000 firmware.bin
```

Перед обычным обновлением не выполняйте `erase-flash`. Перед обслуживанием рекомендуется скачать JSON backup из **System → Configuration backup**.

## HyperHDR

Отдельный Windows-плагин не нужен. Контроллер добавляется в HyperHDR как обычное DDP-устройство:

- протокол: DDP;
- порт: UDP/4048;
- адрес: IP контроллера;
- количество LED: сумма четырёх активных сторон из Web UI.

WLED realtime UDP и HyperHDR Hyperk для этой прошивки использовать не нужно.
