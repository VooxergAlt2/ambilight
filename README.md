# ESP32-C6 Ambilight Controller

Custom ESP32-C6 Ambilight endpoint for HyperHDR.

The project is developed in small hardware-validated stages. The initial implementation focuses on four synchronized WS2812-class LED outputs through ESP32-C6 PARLIO. Network transport, USB/AWA, VL53L5CX adaptive brightness, failover, and management features are added only after the LED engine is proven stable.
